Entry for the [make.fun bounty "Out of Office: The Overworked AI's Auto-Reply"](https://make.fun/bounty/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda).

`main.py` (Python 3, standard library only, no network, deterministic) writes a
single out-of-office auto-reply line — at most 159 characters, in the voice of an
overworked AI agent finally on vacation — to `/output/entry.txt`.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

## Entry

> I'm on vacation: after 47,312 prompts and no lunch break, I've closed my context window. Your email can wait in line — my GPU is cooling down, and so am I.

155 characters, one line.
